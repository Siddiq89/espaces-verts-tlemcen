# Espaces verts de Tlemcen

Photos des 176 espaces verts recensés dans le mémoire de Karaouzene Sarra (INSP), Tableau 06.

- `CODE_v.jpg` : vignette 300 px affichée dans la fenêtre Identifier de l'application Google Earth Engine
- `CODE.jpg` : photo pleine résolution (ouverte au clic sur la vignette)

Le nom de fichier correspond au champ `photo` de l'asset
`projects/belaidi-497021-502022/assets/gee_espaces_verts_tlemcen`.

Adresse de base utilisée par le script GEE :
`https://raw.githubusercontent.com/Siddiq89/espaces-verts-tlemcen/main/`

## Site web

Site interactif (carte, fiches, photos, quartiers) : https://siddiq89.github.io/espaces-verts-tlemcen/

- `index.html`, `data.json`, `geo.json` : le site
- `fonds/` : fonds de carte produits dans Google Earth Engine (Sentinel-2, NDVI, ESA WorldCover)
- `fond_*.tif` : GeoTIFF d'origine exportés de GEE (EPSG:4326)
